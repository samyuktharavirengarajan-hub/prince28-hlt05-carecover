
# CareCover – Requirements

## Functional Requirements

1. The system must allow users to search for at least 50 medical procedures.

2. The system must support both PM-JAY and Tamil Nadu CMCHIS schemes.

3. The system must display the package code and package rate for each available procedure.

4. The system must indicate whether pre-authorisation is required and whether the procedure is restricted to government hospitals.

5. The system must display information about at least 20 verified medical package records.

## Non-Functional Requirements

1. The API must respond to 95% of normal requests within 2 seconds.

2. The system must achieve at least 90% accuracy across 50 procedure-related test questions.

3. The API must support at least 100 concurrent users during testing.

4. The application must return a clear error response for invalid requests within 1 second.

5. The system must maintain at least 99% availability during the testing period.
